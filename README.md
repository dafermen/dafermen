# Hi, I'm Dario Meneses

I build practical software, automation tools, learning products, dashboards, and applied AI experiences for real-world problems.

My work brings together full-stack development, accessible interfaces, operational visibility, and tools that help people learn and make better decisions. [Innovalogic.tech](https://innovalogic.tech/) is my portfolio and consulting website.

## What I Build

- Learning platforms, language practice tools, and accessible reading experiences
- Dashboards, workflow applications, and operational monitoring tools
- AI assistants and tools for human oversight of software development
- Web applications, desktop utilities, and mobile foundations

## Projects

These projects span working demos, local applications, and products under development. Repository documentation describes each project's current scope and setup.
